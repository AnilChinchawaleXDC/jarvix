# Jarvix

Jarvix is an AI-powered crypto command center designed to streamline your blockchain interactions, portfolio management, and DeFi operations through intelligent automation.

## Overview

Jarvix brings together the power of artificial intelligence and cryptocurrency to provide a unified command center for crypto enthusiasts, traders, and developers.

## Features

- 🤖 AI-powered insights and automation
- 💼 Portfolio tracking and management
- 🔗 Multi-chain support
- 📊 Real-time market data
- 🔒 Secure wallet integration

## Getting Started

### Prerequisites

- Node.js (v18+)
- Python (v3.10+)
- Docker (optional)

### Installation

```bash
git clone https://github.com/siddhijadhav27/jarvix.git
cd jarvix
npm install
```

### Development

```bash
npm run dev
```
